# P1-03 — Live host fixture and evidence runner

## 의존성

P0-09

## 목적

Create disposable fixture projects and evidence records for live mutation verification.

## 대상 파일

- `fixtures/*`
- `e2e/live-host/*`
- `scripts/*`
- `src/evidence/*`

## 구현 지시

1. 현재 코드를 먼저 조사해 같은 기능이 다른 이름 또는 raw adapter에 이미 존재하는지 확인한다.
2. 공개 계약, backend 구현, verifier, tests, docs를 한 작업 단위로 맞춘다.
3. 지원 여부는 추정하지 말고 handler와 live/runtime capability로 판정한다.
4. 변이는 dispatch 전/후 경계를 명확히 하고 unknown outcome을 자동 재실행하지 않는다.
5. 사용자 요구인 `trusted_unattended`의 작업별 승인창 0회를 침해하지 않는다.

## 완료 기준

- [ ] No real user project is touched
- [ ] Evidence includes host build and API fingerprint
- [ ] Fixture restore is verified

## 필수 검증

- `npm run validate:uxp-plan`
- `new fixture plan tests`
- `live run when available`

## Codex 보고 항목

- 변경 파일
- 핵심 설계 결정
- 테스트 결과
- 수행하지 못한 live 검증과 이유
- 남은 위험
