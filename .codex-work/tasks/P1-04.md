# P1-04 — Versioned UI semantic adapter registry

## 의존성

P0-08, P1-03

## 목적

Replace broad descendant traversal with versioned, targeted semantic adapters and postcondition verifiers.

## 대상 파일

- `windows-ui-agent/*`
- `src/bridge/ui-named-pipe.ts`
- `src/features/ui/*`

## 구현 지시

1. 현재 코드를 먼저 조사해 같은 기능이 다른 이름 또는 raw adapter에 이미 존재하는지 확인한다.
2. 공개 계약, backend 구현, verifier, tests, docs를 한 작업 단위로 맞춘다.
3. 지원 여부는 추정하지 말고 handler와 live/runtime capability로 판정한다.
4. 변이는 dispatch 전/후 경계를 명확히 하고 unknown outcome을 자동 재실행하지 않는다.
5. 사용자 요구인 `trusted_unattended`의 작업별 승인창 0회를 침해하지 않는다.

## 완료 기준

- [ ] No arbitrary selector API
- [ ] Targeted FindFirst/ancestor-chain lookup
- [ ] Adapter is gated by host build/locale/fingerprint

## 필수 검증

- `dotnet tests`
- `UI adapter contract tests`
- `live UI test when available`
